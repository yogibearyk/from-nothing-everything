# From Nothing, Everything — Interactive Edition

This is the MDX (Markdown + React) version of the book, with embedded
interactive visualizations.

## Visualizations included

| Component | Chapter | What it shows |
|-----------|---------|---------------|
| `PhysicalTower` | Introduction | Interactive walkthrough of stages 1-12, from identity to the dark sector |
| `UniverseGravity` | Ch 25 | How gravity emerges from the tower — 89 modes, G = 1/89² |
| `screening_tinted_glass.svg` | Introduction | The screening concept: each layer dims like tinted glass |
| `screening_tower_growth.svg` | Ch 10 | The tower growing by Fibonacci stages |
| `carry_cascade_all_stages.svg` | Ch 11 | The carry cascade across all stages |

## To run locally

```bash
npm install
npm run dev
```

## The canonical text version

The plain Markdown version (`from_nothing_everything_v8.md`) remains the
canonical readable version — it works on GitHub, in any text editor, and
requires no build system. This MDX version adds interactivity on top.
